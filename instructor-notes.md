title: 'Instructor Notes'
---

what equipment is needed:
  Pi
  SD card
  screen
  keyboard
  network cables
  switch
  router

you will need an example dataset for the data transfer section. This can be either:
 * downloaded from the internet
 * preloaded on the SD card
 * generated from random or empty data by the learner
 * share it over your local network via NFS or HTTP

different scenarios for setting up equipment:
* how to connect to the internet: phone, router with 4/5G, router to your local network
* file server for sharing data
* example data files (gutenberg, some images, fasta file for gene sequence, netcdf file for environmental data)

shopping list of suggested equipment:
tplink NX510v (5G router with ethernet and WiFi, no USB)
